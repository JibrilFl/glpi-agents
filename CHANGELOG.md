# История изменений

## v1.0.0 — первый релиз

- Установка GLPI Agent 1.16 по SSH с автоматическим выбором Astra Linux или Linux Mint.
- Локальное окно для IP-адреса, SSH-логина, пароля и URL сервера GLPI.
- Подтверждение ключа SSH-узла, скрытый ввод пароля и отображение ошибок установки.
- Передача всех файлов выбранного установщика, включая конфигурацию Astra с URL из окна.
- Краткий вывод этапов и ошибок без перегрузки окна подробными строками пакетов.
- Переносимая сборка для Windows, запускаемая без установленного Python.
- `.env` исключён из Git и релизного архива; адрес GLPI вводится в окне или задаётся локально рядом с `.exe`.

Проверено пользователем: установка завершилась, устройства появились в GLPI, переносимая версия работает на целевом ПК.
