# План: локальный установщик GLPI Agent

Статус: завершён

## Цель и требования

Администратор устанавливает GLPI Agent по SSH через простое локальное окно. Требования и границы первой версии: [SPEC.md](../SPEC.md).

## Исходное состояние

В репозитории были документы шаблона, скрипты Astra/Mint и два установочных пакета GLPI Agent 1.16. Приложения и тестов не было. В конфигурации Astra и скрипте Mint был одинаковый внутренний адрес GLPI; `.env` уже указан в `.gitignore`. `python` 3.12, `tkinter` и `paramiko` доступны в текущей среде. Реального тестового Linux-узла здесь нет.

## Решения и допущения

- Локальное окно на Python/Tkinter: выбрано пользователем; дополнительный UI-сервис не нужен.
- URL GLPI вводится в окне; `.env` даёт видимое, редактируемое начальное значение: сочетает оба требования пользователя.
- Для SSH используется Paramiko и подтверждение отпечатка неизвестного ключа. Пароль остаётся только в памяти процесса.
- Установочные пакеты и существующие скрипты используются как исходный путь установки; поддержка иных ОС откладывается.

Блокирующих вопросов нет. Пользователь подтвердил успешную установку, появление ПК в GLPI и работу переносимой версии.
