# GLPI Agent Installer v1.0.0

Первый релиз локального установщика GLPI Agent 1.16 для Astra Linux и Linux Mint.

## Использование

1. Скачайте `GLPI-Agent-Installer.zip` из файлов этого релиза.
2. Распакуйте архив целиком на Windows-ПК. Python устанавливать не требуется.
3. Запустите `GLPI-Agent-Installer.exe`, введите IP устройства, SSH-логин, пароль и URL сервера GLPI.
4. Подтвердите отпечаток SSH-ключа после сверки с устройством и дождитесь результата.

Архив содержит `.exe`, необходимые библиотеки и оба пакета GLPI Agent. Локальный `.env` в релиз не включён.
